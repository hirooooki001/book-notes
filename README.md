# かみくだき読書ノート

読んだ本を自分の言葉で要約して公開するブログです。
目的は「読んだ本をかみくだいて説明する力」をつけること。

## 書き方（毎回これだけ）

1. `book-notes` フォルダの **`start.command` をダブルクリック**
   （初回だけ「開発元を確認できません」と出たら、右クリック →「開く」）
2. ブラウザで「書く」画面が開くので、フォームを埋める
   - 右側にプレビューがリアルタイムで出ます
   - 入力中の内容は自動で下書き保存されます
3. **「保存して記事にする」** を押す → 記事が `books.js` に保存されます
4. 書き終わったら、黒いターミナル画面を閉じて終了

既存の記事を直したいときは、記事ページの「✎ この記事を編集」か、書く画面の上のプルダウンから選びます。

### 書く項目（説明力を鍛える順番）

| 項目 | ねらい |
|---|---|
| 一言でいうと（30字） | 核心をつかむ |
| なぜ読んだか | 目的意識をはっきりさせる |
| 3つの要点 | 取捨選択する |
| 中学生に説明するなら | 専門用語を言い換える |
| 身近な例でいうと | 抽象→具体に落とす |
| 自分の考え | 受け身で終わらせない |
| 明日から試すこと | 行動につなげる |
| 理解度（1〜5） | どこが弱いか自覚する |

コツ：**本を閉じてから書く**。書けないところ＝まだ説明できないところです。

## ファイル構成

- `index.html` … トップ（記事一覧・検索・ジャンル絞り込み）
- `book.html` … 記事ページ
- `write.html` / `write.js` … 書く画面（自分のPCでだけ動く）
- `books.js` … 記事データ（書く画面が自動で更新）
- `server.py` / `start.command` … 書く画面用のローカルサーバー
- `style.css` / `app.js` … 見た目と表示処理
